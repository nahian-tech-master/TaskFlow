# TaskFlow

TaskFlow is a modern task management web application built as a production-style full-stack project.

The goal of this project is to build a real-world application while practicing modern web development, scalable project structure, authentication, APIs, database management, and deployment.

## 🚀 Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB

### Tools
- Git
- GitHub

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/nahian-tech-master/TaskFlow.git
```

### 2. Navigate to the project

```bash
cd TaskFlow
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
